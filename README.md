# odin-recipes

## Project Description
The **Odin Recipes** project is my first hands-on web development assignment from [The Odin Project](https://www.theodinproject.com). The goal of this project is to build a basic recipe website from scratch. It features a main index page that links out to various recipe pages, each detailing ingredients, descriptions, and preparation steps for specific dishes. 

This project is primarily focused on structuring content correctly and establishing a solid, repeatable development workflow using version control.

## Skills Demonstrated
By completing this project, I will have successfully demonstrated and practiced the following foundational software engineering skills:

### 1. Git & GitHub Version Control
* **Repository Management:** Creating remote repositories on GitHub and cloning them to a local machine via SSH.
* **Atomic Commits:** Saving progress incrementally with clear, concise commit messages.
* **Remote Syncing:** Pushing local changes safely up to a remote repository (`git push`).

### 2. HTML Foundational Structuring
* **Document Architecture:** Writing clean boilerplate code, including `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>` tags.
* **Text Formatting:** Using headings (`<h1>` through `<h3>`), paragraphs (`<p>`), and emphasizing text correctly.
* **List Elements:** Organizing data using both ordered lists (`<ol>`) for sequential steps and unordered lists (`<ul>`) for ingredients.
* **Hyperlinks & Media:** Implementing absolute links to external sites, relative paths to internal files, and embedding images properly using the `<img>` tag.
